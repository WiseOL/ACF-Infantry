# Starting ammo

All 21 guns and launchers now have Primary.DefaultClip = Primary.ClipSize + 100. On a fresh give/spawn, this supplies a full magazine plus 100 reserve rounds. Existing magazine capacities are unchanged. Grenades and utility SWEPs are unchanged.

Garry's Mod shares reserve ammunition between weapons using the same ammo type. Existing inventory, repeated weapon pickups, and server ammo caps can therefore affect the displayed reserve total; this change does not reset or remove a player's existing ammo.
